# 日本語の世界 — Volumes 0–6

Static, reading-first Japanese learning website for GitHub Pages. All seven volumes are now represented with lessons.

For updating an existing Volumes 0–5 site, use the **Volume 6 Changes Only** ZIP. For a fresh installation, use the **Volumes 0–6 Full Site** ZIP and upload its contents to your GitHub Pages publishing directory.

Volume 6 adds 20 beyond-N1-oriented lessons about interpretation, register, dialect, rhetoric, media literacy, translation and original writing. Short guided lessons do not constitute a comprehensive advanced textbook or guarantee native-like fluency.
